# MC百科 / 9minecraft 摘要

## 一句话摘要
> Xiaozhi TPA —— 服务端专用 `TPA / 回家 / 返回` 模组，支持 `/home /tpa /back`，按维度多座命名家、TPA 60 秒超时、自动接受开关，数据存档持久化，中文+英文。

## 功能列表
- `/tpa <玩家>`、`/tpaccept`、`/tpdeny`、`/tpauto`：玩家间传送请求与开关自动接受
- `/sethome`、`/home`、`/delhome`、`/listhome`：多座命名家，按维度区分
- `/back`：返回死亡或传送前位置
- TPA 请求 60 秒超时；所有数据存档持久化
