## 一句话简介
> 一个服务端专用的 TPA / 回家 / 返回 模组：`/tpa /tpaccept /tpdeny /tpauto`、`/sethome /home /delhome /listhome`、`/back`，支持按维度多座命名家、TPA 60 秒超时、数据存档持久化，中文+英文。

## 命令列表（所有版本一致）
| 命令 | 说明 |
|---|---|
| `/tpa <玩家>` | 发送传送请求；对方开启自动接受则立即传送 |
| `/tpaccept [玩家\|all]` | 接受请求 |
| `/tpdeny [玩家]` | 拒绝请求 |
| `/tpauto` | 开关自动接受 |
| `/sethome <名字>` | 把当前位置存为家（按维度） |
| `/home [名字]` | 回到指定家（无参用默认 `home`，带自动补全） |
| `/delhome <名字>` | 删除家 |
| `/listhome` | 列出当前维度的家 |
| `/back` | 返回上一位置（死亡或传送前记录） |

## 安装
把对应加载器/版本的 jar 放入服务器 `mods/` 目录即可（客户端无需安装）。
